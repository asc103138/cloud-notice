# 家長通知中心（Google Apps Script）

這是一個以 Google 試算表作為資料庫、Google Drive 保存圖片的家長通知保存系統。

## 功能

- 管理者可在試算表或管理側邊頁新增、編輯、發布與取消發布通知。
- 家長可從 Web App 公開網址查看已發布通知。
- 依月份與四種分類篩選：收費通知、課程通知、報名通知、圖片通知。
- 通知日期會自動產生月份；可設定置頂、開始顯示日與結束顯示日。
- 圖片集中上傳至 Google Drive，單張限制 8 MB。
- 第一版不串接 LINE Official Account API，也不會自動發送訊息。

## 建立方式

1. 新增一份 Google 試算表，名稱可自訂。
2. 開啟「擴充功能 > Apps Script」，將 `Code.gs`、`Index.html` 與 `appsscript.json` 放入同一個 Apps Script 專案。
3. 儲存後回到試算表並重新整理頁面。
4. 從試算表選單選擇「家長通知系統 > 初始化系統」。初始化會建立 `通知資料`、`系統設定` 工作表與一個 `家長通知圖片` Drive 資料夾。
5. 初始化時使用的 Google 帳號會成為唯一管理者。之後請用同一帳號從「家長通知系統 > 開啟管理頁」操作。

## 部署公開頁

1. 在 Apps Script 選擇「部署 > 新增部署作業」。
2. 類型選「網頁應用程式」。
3. 「執行身分」選擇自己；「誰可以存取」依需求選擇「任何人」或「任何知道連結的使用者」。
4. 部署後複製 Web App URL，這個網址的預設頁面就是家長公開頁。
5. 管理功能建議從試算表側邊頁開啟，不要把管理網址公開給家長。

如果以 `?view=admin` 開啟管理頁，Apps Script 必須能辨識目前登入的 Google 帳號；若出現權限錯誤，請改從綁定試算表的自訂選單開啟。

## 通知資料欄位

`通知資料` 工作表的欄位如下：

| 欄位 | 用途 |
| --- | --- |
| ID | 系統自動產生，不要修改 |
| 標題 | 家長看到的通知標題 |
| 通知日期 | 用來產生月份與排序 |
| 月份 | 系統依通知日期自動產生 |
| 分類 | 收費通知、課程通知、報名通知、圖片通知 |
| 通知內容 | 文字內容，可換行 |
| 圖片檔案ID／圖片網址 | 管理頁上傳圖片後自動填入 |
| 已發布 | 勾選後才會出現在公開頁 |
| 置頂 | 勾選後優先顯示 |
| 開始顯示日／結束顯示日 | 可選的公開期間 |
| 建立時間／更新時間 | 系統自動記錄 |

直接在試算表編輯通知日期時，程式內的 `onEdit` 簡易觸發器會同步更新 ID、月份與更新時間。

## 圖片與個資注意事項

- 公開頁不應放家長姓名、電話、孩童個別資料或其他可識別個資。
- 上傳圖片時，程式會嘗試設定為「知道連結的使用者可查看」，這樣家長公開頁才能顯示圖片。
- 若學校 Google Workspace 政策禁止公開連結，圖片仍會上傳，但公開頁可能無法顯示；請改由管理員調整 Drive 共用政策或使用允許公開顯示的圖片來源。

## 本地檢查

這個專案需要在 Apps Script 執行，不能直接用一般瀏覽器開啟 `Index.html`。提交前可先確認：

- `Code.gs`、`Index.html`、`appsscript.json` 均已放入同一個 Apps Script 專案。
- 初始化後能看到 `通知資料` 與 `系統設定` 工作表。
- 管理頁新增一筆草稿、上傳圖片、再勾選發布。
- 公開 URL 只能看到已發布且在有效日期內的通知。
